A make.fun entry for **The Robot Vacuum's Best Excuse**. The program writes one line — a robot vacuum's deadpan excuse for missing a spot — to `/output/entry.txt`.

Run it with Node 22:

```sh
node main.ts
```

The entry line (102 characters):

> I didn't miss that spot — my map labelled it 'cat', and my collision sensor has signed a peace treaty.
